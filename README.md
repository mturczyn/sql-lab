# SQL

A collection of practical SQL examples, scripts, and notes covering queries, database concepts, transactions, and performance.

## Structure

Examples are organized by topic under `src/`, with separate directories for each DBMS where applicable:
```
/
|-- src/
|   |-- IsolationLevels/
|   |   |-- sql-server/
|   |   |   |-- script.sql
|   |-- AnotherTopic/
|   |   |-- postgres/
|   |   |   |-- script.sql
|   |-- ... etc
|-- README.md
```

## Goals

- Explore SQL concepts through practical examples.
- Understand database behavior and features.
- Experiment with transactions, concurrency, and query performance.
- Maintain a reusable reference for learning and development.
